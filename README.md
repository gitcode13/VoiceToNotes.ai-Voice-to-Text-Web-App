# VoiceToNotes.ai — Manual QA Testing Project

Manual testing project for VoiceToNotes.ai (Voice-to-Text Web App), performed as a self-driven QA practice project.

## What's inside
- Test cases covering Functional, Regression, Smoke, Negative, and Edge Case scenarios
- Bug reports with severity/priority classification
- Test artifacts (Excel sheet with test cases and results)

## Scope
Tested 7 functional modules including Authentication, Voice Recording, Transcription, Note Management, and AI Enhancements.

## Tools Used
JIRA, MS Excel
